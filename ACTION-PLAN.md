# 🎯 План действий: от текущего состояния до софт-лонча

Всё, что нужно делать ПО СЛЕДУЮЩИМ ОБРАЗОМ, по шагам. Каждый этап имеет чек-бокс —
не переходите дальше, пока не отмечен текущий. Ориентировочное время полного цикла:
**2–4 дня** «ручной» работы за компьютером.

**Что у вас уже есть:** весь код игры (63 скрипта), весь контент (253 ассета: 14 героев,
56 умений, 26 врагов, 135 уровней, 9 миров), звук (9 файлов), серверная часть (Cloud Functions),
документы (GDD, листинг стора, приватность, реклама). Чего **нет**: Unity-сцен (3 шт.),
собранного APK и задеплоенного сервера — это и есть ваша работа ниже.

## ЭТАП 6. Firebase — сервер (1 час; можно отложить на после первого локального теста)

Пока `GameConfig.apiBaseUrl` пуст, игра полноценно работает офлайн (сейвы локально).
Сервер нужен для: облачных сейвов, общей арены и ЧАТА.

- [ ] **6.1.** https://console.firebase.google.com → Add project → `dream-masters-revival`
  (Google Analytics — можно выключить).
- [ ] **6.2.** Build → **Firestore Database** → Create database → Production mode →
  регион `eur3`/`europe-west`.
- [ ] **6.3.** На компьютере (нужен Node.js из этапа 1.4):
  ```
  npm install -g firebase-tools
  firebase login
  cd <папка репозитория>/unity-project
  firebase init
  ```
  В вопросах выбрать: **Functions** + **Firestore**; existing project → ваш;
  язык функций — **JavaScript**; использовать существующие файлы
  (index.js, firestore.rules уже написаны!) — отвечать «Yes, overwrite/use existing»
  НЕТ там, где спрашивает перезаписать (файлы уже готовы).
- [ ] **6.4.** `firebase deploy --only functions` (2–5 минут).
- [ ] **6.5.** В консоли Firebase → Functions → скопировать адрес функции `profile`:
  например `https://us-central1-dream-masters-revival.cloudfunctions.net`
  (БЕЗ имени функции в конце — базовый URL).
- [ ] **6.6.** Unity → ассет `Resources/DreamMasters/GameConfig` → поле
  **Api Base Url** → вставить URL. Всё: GameManager сам включит облачные сейвы,
  REST-сеть и общий чат.
- [ ] **6.7.** Проверка: поиграйте бой с победой → консоль Firebase → Firestore →
  появилась коллекция `profiles` с вашим anonymousId. Чат: отправьте сообщение
  в игре → коллекция `chat`.

> Бесплатный план Firebase (Spark) хватает на сотни игроков для теста. Перед
> реальным запуском посчитайте лимиты Firestore (чтения/записи в день).

- [ ] **7.3. Иконка** 512×512 PNG + **Feature graphic** 1024×500.
- [ ] **7.4. Скриншоты** минимум 4 шт. 1920×1080 (снимите с телефона в игре или
