Версия 0.1 — вертикальный срез. Основано на досье `research/mastera-snov-issledovanie.md`.

Если права у вас есть (вы участник исходного проекта) — брендинг можно вернуть. Если нет — механики (не охраняются) воспроизводим один в один, а арт/имена/название делаем своими. ## 1. Видение

Файтинг-ориентированная мобильная онлайн-RPG: **автобои с ручной активацией умений отряда из 4 героев**, коллекционирование героев-карт (категории × стихии × синергии), кампания по мирам снов + PvP-арены. Духовный наследник оригинала 2015 года на современном стеке, с исправлением болезней исходника (см. §8).

- **Платформа:** Android (Unity 2022 LTS, C#, URP, **ландшафтная** ориентация)
- **Модель:** онлайн-RPG с локальным боем (клиентская симуляция PvE, сервер — валидация и мета); монетизация — позже, нативная реклама (см. §9)
- **Core loop:** бой → лут (руны, осколки, золото) → прокачка героев (уровень/звёзды/ранг/навыки) → новый герой → сложнее бои → арена

## 2. Вертикальный срез (итерация 1) — что делаем первым

1. Бой: отряд 4 героев против волны врагов + босс, авто-атаки, 4 кнопки умений, автобой-тоггл, джойстик перемещения активного героя.
2. Стихии: Огонь > Воздух > Земля > Вода > Огонь, модификатор урона ±25%.
3. 4 стартовых героя: Эш (ДД, огонь, средняя), Фрэнк (танк, земля, ближняя), Аймер (лекарь, вода, дальняя), Чейни (ДД, вода, дальняя) + 1 босс.
4. Сюжетная завязка: первый бой — гарантированный проигрыш первому боссу (как в оригинале).
5. Мета-минимум: профиль игрока, валюты (золото, кристаллы, осколки), коллекция героев, команда из 4, экран прокачки (уровень кормом/пылью).
6. Сохранения: локально в JSON + интерфейс облачного сохранения (заглушка → сервер).
7. Сеть: интерфейс INetworkService + локальная заглушка (все PvP-функции — мок-данные), чтобы потом подключить бэкенд без переписывания.

## 3. Герои

### Категории (направления)
Легенды / Мифы / Сказки / Предания / Другие. Влияют на доступные синергии (одна категория = больше связей).

### Стихии и урон
| Атакующий | Цель огонь | воздух | земля | вода |
|---|---|---|---|---|
| **Огонь** | ×1.0 | ×1.25 | ×1.0 | ×0.8 |
| **Воздух** | ×0.8 | ×1.0 | ×1.25 | ×1.0 |
| **Земля** | ×1.0 | ×0.8 | ×1.0 | ×1.25 |
| **Вода** | ×1.25 | ×1.0 | ×0.8 | ×1.0 |

### Дальнобойность/роли
Ближняя (танки) / средняя (дамагеры) / дальняя (саппорты). Позиционирование в бою: танк впереди, саппорт сзади.

### Развитие героя (по оригиналу)
- **Уровень 1–60** — корм картами героев или волшебной пылью.
- **Звёзды 1→5..7** — слияние одинаковых карт + камни эволюции. +базовые статы.
- **Ранг (цвета: белый → зелёный → зелёный+1 → синий → синий+1 → фиолетовый)** — 6 рун ранга + камни эволюции; открывает слоты навыков.
- **Навыки (4)** — золото + очки навыков; уровень навыка ≤ уровень героя.
- **Пробуждение** — при макс. звёздах и ранге: смена облика, ×2 к статам.
- **Экипировка** — 6 слотов; «родной» сет героя даёт синергию всему отряду. (В срезе — только каркас.)
- **Синергия** — таблица пар: Чейни+Эш = +20% атаки и т.д.

## 4. Бой

- Изометрическая арена-комната, до 4 героев игрока vs волны мобов + босс.
- Управление: джойстик (перемещение ведущего героя), кнопки 4 умений (кулдауны), тоггл автобоя, ускорение ×2.
- Герои-ИИ: авто-атака ближайшей/приоритетной цели, танки таunt, лекарь лечит самого раненого.
- Урон = ATK × k_навыка × стихия × крит × синергии − защита.
- Комнаты уровня: 3–5 волн, в конце босс; после уровня — экран наград (золото, руны, осколки, экипировка).
- Первый бой кампании — скриптованный проигрыш (канон оригинала).

## 5. Кампания

9 миров × ~15 уровней (срез: мир 1 полностью). Миры = «сны» запертых Мастеров, каждый сон — своя стихия и визуальная тема; финальный босс мира — сам Мастер, после победы присоединяется (как в оригинале: побеждённые присоединяются к отряду).

## 6. PvP (после среза)

- **Арена (авто)**: рейтинг, зал славы, защита отбирается из топ-50 — считается на сервере.
- **Колизей (ручной)**: до 3 поражений в день, награды за пороги побед. Реальное время — Phase 2 (Photon/Netcode), в срезе — мок-противники из локального профиля.

## 7. Сюжет (сохраняем канон)

Повелитель Мрака заточён Мастерами в Вечном Сне → пробудился → заключил каждого Мастера в его собственный сон. Игрок — последний свободный Мастер: проходит сны Мастеров, освобождает героев, собирает отряд, освобождает Королевство.

## 8. Что исправляем по сравнению с оригиналом

| Проблема оригинала | Решение в ремейке |
|---|---|
| Сервера не выдерживали, вылеты, откаты | Бой — локальная симуляция (детерминированная); сервер только валидирует и хранит мету |
| Новый сервер каждую пятницу, слияния | Один мир + матчинг/лиги по рейтингу; аккаунт не привязан к серверу |
| Потеря прогресса при сбоях | Автосохранение после каждого боя, локальный кеш + облачный слепок |
| Привязка только VK | Анонимный ID + Google Play Games (+ экспорт-код) |
| Донат не работал на Android | Монетизация подключается после стабилизации: нативная реклама (см. §9) |
| Нет маркетинга, нет новых игроков | План запуска: софт-лонч, комьюнити VK/Telegram с первых дней, предрегистрация |
| Обучение нельзя было пройти на части устройств | Обучение скипается зажатием экрана 5 сек — оставляем эту же механику «пасхалкой» |

## 9. Монетизация (отложенная, архитектура — сейчас)

Сейчас: **никаких SDK**. В проекте только `IAdService` (заглушка) и серверные транзакции валюты. Точки будущей нативной рекламы зафиксированы в UI: главный экран (меню), экран результатов боя, магазин, лента героев. Подключение после релиза: AdMob Native Ads / медиация, Consent Manager (GDPR), пометка «Реклама», возрастные политики Google Play.

## 10. Техническая архитектура

```
Assets/Scripts/
  Core/        GameManager, PoolManager, SceneLoader, GameConfig
  Data/        ScriptableObject-контент: HeroData, AbilityData, EnemyData, LevelData, SynergyData, HeroCatalog
  Progress/    PlayerProfile, HeroInstance, CurrencyService, HeroCollectionService, InventoryService
  Battle/      BattleManager, BattleUnit, DamageCalculator, AbilityRuntime, WaveController, FloatingDamageText
  Services/    ISaveService + LocalSaveService (JSON), INetworkService + stub, IAdService + NullAdService
  UI/          VirtualJoystick, BattleHUD, SafeAreaFitter, HeroCardView
```

Слои не пересекаются: бой не знает о сохранениях, UI общается с сервисами через события. Данные героев/уровней — в ScriptableObjects (контент без правки кода). Весь сетевой/рекламный код — за интерфейсами.

## 11. Роадмап

3. **Итерация 3:** Firebase (Auth, Firestore, Cloud Functions): аккаунты, облако, лидерборд
4. **Итерация 4:** Арена (авто-PvP серверное), Колизей, друзья, чат

6. **Итерация 6:** софт-лонч → подключение нативной рекламы → релиз
