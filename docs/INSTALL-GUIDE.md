# 💰 Цены и подробная установка «куда что нажимать»

Для тех, кто делал это давно. Здесь: что платно/бесплатно, где регистрироваться,
и каждая установка по кликам. Windows; для macOS логика та же, файлы установщика другие.

### 💳 Итого обязательных трат
- **$25 один раз** — Google Play.
- **Карта в Firebase** — как залог, при тестовых объёмах списаний нет (поставьте бюджет-лимит 0 ₽ в консоли, схема «плати по факту» начнёт работать только за пределами бесплатных квот).

### ⚠️ Важно про Google Play в 2026 (новые правила)
1. На Google-аккаунте обязательна **двухфакторная аутентификация** (2FA).
2. **Верификация личности**: фото паспорта/ID (имя в документе = имя на карте, которой платите $25). Может попросить селфи. Проверка — от пары часов до пары дней.
3. **Правило 12 тестеров**: личный аккаунт перед публичным релизом обязан провести **закрытое тестирование: 12 тестеров, 14 дней**. То есть: 1) собрать список из 12 человек (друзья, семья, группы в VK/Telegram), 2) разогреть тест 2 недели, 3) потом просить разрешение на прод. Закладывайте +2–3 недели в план релиза.
4. Сбор $25 не возвращается, даже если передумаете.

## 2. ПОРЯДОК РЕГИСТРАЦИЙ (все бесплатные, кроме Play)

Делайте прямо в этом порядке:

- [ ] **2.1. Google-аккаунт** (если нет): gmail.com → «Создать аккаунт» → заполнить.
  Это будет ЕДИНСТВЕННЫЙ аккаунт и для Firebase, и для Play Console — сделайте сразу
  «серьёзный» (например `studio.yourname@gmail.com`), а не личный 2007 года.
- [ ] **2.2. Включить 2FA**: myaccount.google.com → «Безопасность» → Двухэтапная
  аутентификация → включить (проще всего — подтверждение на телефон).
- [ ] **2.3. Unity ID:** id.unity.com → «Create one» → email + пароль → подтвердить
  письмо из почты. Запомните — Hub будет спрашивать.
- [ ] **2.4. GitHub** (опционально, но советую): github.com → Sign up. Пригодится для
  бэкапа кода и бесплатного хостинга политики конфиденциальности (GitHub Pages).
- [ ] **2.5. Google Play Console ($25):** можно отложить до готового APK —
  детали в разделе 8 ниже.
- [ ] **2.6. Firebase:** регистрации не требует — входите Google-аккаунтом (раздел 9).

## 3. УСТАНОВКА UNITY — ПО КЛИКАМ

### 3.1. Unity Hub (менеджер версий Unity)
1. Откройте **https://unity.com/download** — страница сама определит ОС.
2. Нажмите большую кнопку **«Download for Windows»** → скачается `UnityHubSetup.exe`.
3. Запустите файл. Если Windows спросит «Разрешить внесение изменений» — **Да**.
4. Установщик: **I agree** (лицензия) → путь оставьте по умолчанию → **Install**.
5. Галочка «Run Unity Hub» → **Finish**. Hub откроется.

### 3.2. Вход и бесплатная лицензия
1. При первом запуске Hub покажет окно входа → **Sign in** → введите Unity ID
   (почта+пароль из п. 2.3). Могут спросить код из письма — введите.
2. Спросит про лицензию (или позже: значок ⚙ слева внизу → **Preferences → Licenses**).
3. Нажмите **Add** → **Get a free personal license** → в открывшемся окне прокрутите
   условия → отметьте галочку возраста → **Agree and activate**.
4. Статус станет «Personal — You are licensed». Это и есть бесплатная лицензия, навсегда.

### 3.3. Установка редактора 2022.3 LTS с Android (самое важное!)
1. В Hub слева: **Installs** (значок «стрелка вниз») → кнопка **Install Editor**.
2. Откроется окно с версиями. Нужна вкладка/строка **Unity 2022.3.x LTS** (помечена
   «LTS», обычно есть в списке сверху; если нет — вкладка **Archive → Official releases →
   2022.3.x → Install**).
3. Нажмите **Install** у этой версии.
4. ⚠️ **ГЛАВНЫЙ ЭКРАН — модули.** В списке отметьте:
   - ✅ **Android Build Support** — и РАСКРОЙТЕ треугольник слева от неё:
     - ✅ **OpenJDK** (должна была встать автоматически — проверьте)
     - ✅ **Android SDK & NDK Tools** (аналогично)
   - (не обязателен, но полезен: **Russian** — переведёт интерфейс редактора)
5. **Continue** → agree → **Install**. Скачается 5–8 ГБ, идёт 15–60 минут.
6. Если пропустили модули — не страшно: Installs → ⚙ у версии 2022.3 → **Add modules**
   → отметьте Android Build Support → Install.

> Забыли модули = билд под Android упадёт с ошибкой «SDK not found» — лечится
> добавлением модулей задним числом (см. выше), ничего не сломается.

## 4. УСТАНОВКА VISUAL STUDIO (редактор кода)

1. **https://visualstudio.microsoft.com/ru/** → прокрутите до **Community 2022** →
   **«Бесплатная загрузка»** → скачается `VisualStudioSetup.exe`.
2. Запустите. Окно «Перед началом» → **Продолжить**.
3. Появится список «Рабочие нагрузки» (плитки с галочками). Отметьте:
   - ✅ **«Разработка игр на Unity»** (Game development with Unity)
4. Нажмите **«Установить»** справа внизу (5–10 ГБ, можно параллельно пить чай).
5. После установки один раз свяжите с Unity: откройте любой Unity-проект →
   **Edit → Preferences → External Tools** → поле **External Script Editor** →
   выберите **Visual Studio 2022**. (Двойной клик по скрипту в Unity теперь откроет VS.)

## 5. УСТАНОВКА NODE.JS (для сервера Firebase)

1. **https://nodejs.org** → большая зелёная кнопка с припиской **LTS** (должна быть
   версии 20.x или выше) → скачать `.msi`.
2. Запустить → Next → принимаете лицензию → Next → Next → Install → Finish.
3. Проверка: **Win+R** → набрать `cmd` → Enter → в чёрном окне:
   ```
   node -v
   ```
   → Enter → должна показаться версия (например `v20.11.0`). Окно закрыть.

## 6. ТЕЛЕФОН: включить отладку по USB

1. **Настройки → О телефоне** (или «Сведения о телефоне»).
2. Найдите строку **«Номер сборки»** (иногда внутри «Сведения о ПО») → тапните по ней
   **7 раз подряд** → появится тост «Вы стали разработчиком!».
3. Вернитесь в Настройки → появилась строка **«Для разработчиков»** → откройте.
4. Включите переключатель **«Отладка по USB»** → ОК в предупреждении.
5. Подключите телефон кабелем к ПК → на телефоне выпадет окно «Разрешить отладку USB?»
   с отпечатком → поставьте галочку «Всегда» → **Разрешить**.

## 8. РЕГИСТРАЦИЯ GOOGLE PLAY CONSOLE ($25) — ПОДРОБНО

> Делать, когда APK уже собран и работает на телефоне. Не раньше — $25 не возвращается.

1. **https://play.google.com/console** → войти своим Google-аккаунтом (с 2FA!).
2. Кнопка **«Создать аккаунт и заплатить взнос»** / «Sign up».
3. Выбор типа: **«Личный» (Personal)** — для нас.
4. Оплата **$25**: нужна обычная дебетовая/кредитная карта (НЕ виртуальная предоплаченная —
   Google их отклоняет; из РФ карты не работают — нужна карта, принимающая платежи в
   Google, эмитированная вне ограничений, либо зарубежная). Страна аккаунта выбирается
   один раз и навсегда.
5. Согласие с **Developer Distribution Agreement** → Create account.
6. **Верификация личности** (новое): Console попросит загрузить фото документа
   (паспорт/права/ID) и, возможно, селфи. Имя документа = имя владельца карты.
   Статус проверки виден в Console сверху; занимает часы–дни.
7. Заполнить **профиль разработчика**: отображаемое имя (его увидят игроки —
   продумайте), email для связи, сайт (можно пусто/Google Sites).
8. После активации аккаунта: слева **Тестирование → Internal testing** — это ваш
  трек для первого APK ( ACTION-PLAN, этап 7.8).
9. Помните про **правило 12 тестеров / 14 дней** (раздел 1): заведите список людей
   заранее, чтобы не ждать потом.

## 9. FIREBASE — ГДЕ «РЕГИСТРИРОВАТЬСЯ»

Отдельной регистрации нет: входите Google-аккаунтом (тот же, что для Play).

1. **https://console.firebase.google.com** → «Войти» → выбрать ваш аккаунт.
2. **«Создать проект»** → имя `dream-masters-revival` → Analytics: можно выключить →
   «Создать проект» → через полминуты «Продолжить».
3. Меню слева → **Build → Firestore Database** → «Create database» → **Production mode**
   → регион `europe-west` (или `eur3`) → Enable.
4. ⚠️ **Про карту (план Blaze для Cloud Functions):** меню слева внизу — план/**Upgrade**
   → **Blaze** → привязать карту. До бесплатных лимитов платить не нужно; для спокойствия:
   после апгрейда откройте **Billing → Budgets & alerts → Create budget** → сумма 0 или
   маленькая + уведомления — тогда сюрпризов не будет в принципе.
   Не готовы давать карту сейчас? Пропустите деплой функций — игра полноценно
   работает офлайн, сервер подключите позже в любой день.
5. Дальше — ACTION-PLAN, этап 6.3 (firebase init / deploy в терминале).
