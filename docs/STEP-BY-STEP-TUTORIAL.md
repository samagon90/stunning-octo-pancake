# 🎮 Пошаговый туториал: Unity-игра на бесплатных нейросетях

> Для полного новичка. Каждый клик описан. Промпты копируются целиком.
> Время прохождения: 1 вечер на главу.

---

## ГЛАВА 1. Регистрация на всех сервисах (30 минут)

### 1.1. Unity (движок)

1. Откройте браузер → **https://unity.com/download**
2. Нажмите синюю кнопку **«Download for Windows»**
3. Скачается файл `UnityHubSetup.exe` → запустите двойным кликом
4. Установщик: **I agree** → **Install** → **Finish**
5. Unity Hub открылся → справа вверху кнопка **«Sign in»** → **«Create account»**
6. Заполните: email, пароль, имя → **«Create account»** → подтвердите почту (зайдите на email, откройте письмо от Unity, нажмите кнопку)
7. Вернитесь в Unity Hub → войдите
8. Слева иконка ⚙ (Preferences) → **Licenses** → кнопка **Add** → **Get a free personal license** → поставьте галочку возраста → **Agree and activate**
9. Слева иконка ↓ (**Installs**) → кнопка **«Install Editor»**
10. Выберите вкладку **«Official releases»** → найдите **Unity 2022.3.x LTS** → кнопка **Install**
11. ⚠️ ГЛАВНОЕ: в списке модулей отметьте галочки:
    - ✅ **Android Build Support**
    - ✅ **OpenJDK** (под ним)
    - ✅ **Android SDK & NDK Tools** (под ним)
12. **Continue** → **Install** → ждите 20-40 мин (качается 5-8 ГБ)

### 1.2. DeepSeek (код)

1. **https://chat.deepseek.com**
2. Кнопка **«Sign up»** → email + пароль → подтвердите
3. Готово — можно сразу писать запросы. VPN не нужен.

### 1.3. Kandinsky (арт, безлимитный)

1. **https://fusionbrain.ai**
2. Кнопка **«Войти»** → регистрация через email или VK
3. После входа → кнопка **«Создать»** (или «Генерация»)

### 1.4. Suno (музыка)

1. **https://suno.com**
2. Кнопка **«Sign up»** → через Google-аккаунт (проще всего)
3. Бесплатно 50 кредитов/день = 10 треков

### 1.5. Meshy (3D-модели, если нужны)

1. **https://meshy.ai**
2. **«Sign up»** → Google или email
3. Бесплатно 100 кредитов/мес ≈ 10 моделей

## ГЛАВА 2. Генерация героя в Kandinsky (10 минут на персонажа)

### 2.1. Пишем промпт

Откройте fusionbrain.ai → «Создать» → в поле ввода вставьте (можно на русском!):

```
Милый мультипликационный игровой персонаж в стиле AFK Arena:
каменный голем-страж, массивное тело из серо-зелёных валунов со
светящимися зелёными рунами, маленькие добрые глаза, держит
огромный круглый каменный щит, полный рост, вид сбоку, смотрит
вправо, на сплошном ярко-фиолетовом (#FF00FF) фоне, без тени,
без земли, без текста, чистый игровой спрайт
```

**Замена персонажа** — просто замените описание:

| Кто | Что писать вместо «каменный голем...» |
|---|---|
| Воин с мечом | «молодой воин с огненным мечом, рыжие волосы, красно-золотая броня, горящий клинок» |
| Лекарь | «девушка-целительница, длинные сине-белые волосы, бело-голубая мантия, посох со светящимся синим шаром» |
| Маг | «девушка-гейша с сямисеном, голубое кимоно с узором волн, блестящие заколки» |
| Враг | «маленький огненный имп из красно-оранжевого пламени, сонные озорные глаза» |
| Босс | «громадный тёмный повелитель в чёрно-фиолетовой броне с шипами, злая чёрная корона, фиолетовое пламя» |

### 2.2. Генерируем

1. Вставили промпт → кнопка **«Сгенерировать»** (или «Применить»)
2. Получите 1-4 картинки → выберите лучшую → **скачайте** (иконка ⬇)
3. Файл сохранится как `kandinsky_xxx.png`

### 2.3. Дополнительные позы (для анимации)

Того же персонажа сгенерируйте ещё раз, меняя последнее предложение:

| Поза | Что добавить в конец промпта |
|---|---|
| Шаг 1 | «...одна нога поднята на шаге, корпус отклонён назад» |
| Шаг 2 | «...ноги расставлены на ширине плеч, корпус наклонён вперёд» |
| Замах | «...рука с оружием отведена далеко назад, корпус скручен» |
| Удар | «...оружие вытянуто вперёд, корпус наклонён вперёд» |
| Заклинание | «...обе руки подняты вверх, вокруг рук светится магия» |

⚠️ Оставляйте описание персонажа ИДЕНТИЧНЫМ — меняйте только позу.

### 2.4. Обработка (вырезка фиона)

**Если пользуетесь моим проектом:**
```bash
# положите все скачанные PNG в папку prototype/art/raw/
# запустите:
python3 tools/build_demo_art.py
```
Скрипт сам: вырежет фиолетовый фон → сделает прозрачный PNG → уменьшит → положит в `art/proc/`

**Если вручную (без проекта):**
1. **https://www.remove.bg** → загрузите картинку → фон удалится → **Download**
2. Или в Photoshop/GIMP: волшебная палочка → клик по фиолетовому → Delete

## ГЛАВА 3. Генерация кода в DeepSeek (15 минут)

### 3.1. Первый запрос (знакомство с проектом)

Откройте **chat.deepseek.com** → в поле ввода вставьте:

```
Прочитай эти два документа и подтвердите, что понял проект:

[ВСТАВЬТЕ СОДЕРЖИМОЕ ФАЙЛА android-game-llm-prompt.md]

[ВСТАВЬТЕ СОДЕРЖИМОЕ ФАЙЛА PROJECT-HANDOFF.md]
```

DeepSeek ответит «Понял, это...» — значит контекст загружен.

### 3.2. Запрашиваем фичу

Дальше просто пишете задачи русским языком:

```
Добавь систему ежедневных наград:
- раз в день игрок получает золото и осколки
- кнопка в меню
- счётчик до следующей награды
- сохранение в localStorage
```

Или:

```
Добавь нового босса "Ледяной Дракон":
- спрайт ice_dragon.png уже лежит в prototype/art/raw/
- 3 фазы боя
- атака ледяным дыханием (конус)
-_dropRate: 50 осколков
```

Или для Unity:

```
Напиши C# скрипт для Unity: система инвентаря с 20 слотами,
предметы перетаскиваются мышью, сохранение в JSON
```

### 3.3. Получили код → что делать

1. DeepSeek выдаст блок кода в серой рамке
2. Кнопка **«Copy»** в правом верхнем углу блока → копировали
3. Для веб-версии: откройте `prototype/index.html` в блокноте → Ctrl+F → найдите место → вставьте
4. Для Unity: создайте файл в `Assets/Scripts/` → вставьте код → сохраните

### 3.4. Если код не работает

Скопируйте текст ошибки → вставьте в DeepSeek:
```
Вот ошибка:
[текст ошибки]

Вот код:
[код]

Исправь
```

## ГЛАВА 5. 3D-модели в Meshy (если нужны для Unity)

### 5.1. Генерация

**https://meshy.ai** → **«Text to 3D»**:

```
cute chibi stone golem guardian, low-poly game character,
green-grey rock body with glowing runes, holding round shield,
stylized mobile game style
```

→ **«Generate»** → ждите 2-3 мин → вращайте модель → если нравится → **«Download»** → формат **FBX**

### 5.2. Анимация через Mixamo

1. **https://www.mixamo.com** → войдите через Adobe ID (бесплатно)
2. **«Upload Character»** → загрузите FBX
3. Справа библиотека анимаций → выберите:
   - **Idle** (стояние)
   - **Running** (бег)
   - **Attack** (атака)
   - **Death** (смерть)
4. На каждую: **«Download»** → формат FBX → «With Skin»
5. Все FBX → в Unity `Assets/Models/`

## ГЛАВА 6. Сборка в Unity (2-3 часа)

### 6.1. Создаём проект

1. Unity Hub → **New project**
2. Шаблон **«3D (URP)»**
3. Name: `DreamMastersRevival`
4. ⚠️ Путь — только латиница: `C:\Games\DreamMastersRevival`
5. **Create project** → ждите 10 мин

### 6.2. Импорт кода

1. Откройте папку репозитория → `unity-project/Assets/Scripts/`
2. Скопируйте ВСЁ содержимое (Ctrl+A → Ctrl+C)
3. Вставьте в `C:\Games\DreamMastersRevival\Assets\` (Ctrl+V)
4. Переключитесь в Unity → подождите компиляции
5. Если предлагает импортировать **TextMesh Pro** → соглашайтесь

### 6.3. Импорт спрайтов

1. Скопируйте файлы из `prototype/art/proc/` (прозрачные PNG)
2. Вставьте в `Assets/Sprites/` (создайте папку: правый клик в Project окне → Create → Folder)

### 6.4. Импорт музыки

1. MP3 из Suno → в `Assets/Audio/`
2. Unity автоматически импортирует

### 6.5. Настройки Android

**Edit → Project Settings → Player:**
- Company Name: ваше имя
- Product Name: `Dream Masters Revival`
- **Other Settings**:
  - Package Name: `com.yourname.dreammasters`
  - Minimum API Level: **24**
  - Scripting Backend: **IL2CPP**
  - Target Architectures: **ARM64** ✅
- **Resolution**: Orientation → **Landscape**

**File → Build Settings:**
- Платформа **Android** → **Switch Platform** (ждать)

### 6.6. Создание сцен

**Сцена Boot:**
1. File → New Scene → сохранить как `Boot`
2. Правый клик в Hierarchy → **Create Empty** → назвать `Bootstrap`
3. Выделите `Bootstrap` → Inspector → **Add Component** → поиск:
   - `GameManager` → добавить → перетащить ассет `GameConfig` в поле Config
   - `PoolManager`
   - `BootFlow`
   - `AudioManager`

**Сцена Home:**
1. File → New Scene → `Home`
2. Правый клик → **UI → Canvas** → в Inspector:
   - Canvas Scaler → Scale With Screen Size → **1920×1080**
   - Add Component → `SafeAreaFitter`
   - Add Component → `UiClickBinder`
3. Создавайте панели: правый клик на Canvas → **UI → Panel** → переименовать

**Сцена Battle:**
1. File → New Scene → `Battle`
2. GameObject → **3D Object → Plane** → Scale (3,1,3)
3. Камера: Position (0, 12, -14), Rotation (55, 0, 0)
4. Пустой объект `Battle` → компоненты: `BattleManager`, `WaveController`, `BattleSceneBootstrap`

### 6.7. Добавить все 3 сцены в Build

**File → Build Settings** → **Add Open Scenes** (для каждой сцены откройте её и нажмите)

### 6.8. Сборка APK

1. Телефон: Настройки → О телефоне → 7 тапов по «Номер сборки»
2. Настройки → Для разработчиков → **Отладка USB** ✅
3. Подключите телефон кабелем
4. Unity: **File → Build And Run** → APK на телефоне

## Экстренная шпаргалка

| Проблема | Решение |
|---|---|
| Unity не видит скрипты | Убедитесь что файлы .cs в Assets/, перезапустите Unity |
| Ошибка компиляции | Ctrl+A в Console → скопировать → в DeepSeek «исправь» |
| Спрайт с фоном | `python3 tools/build_demo_art.py` или remove.bg |
| Музыка не играет в Unity | Проверьте что есть AudioSource на объекте |
| APK не ставится | Включите «Неизвестные источники» в настройках телефона |
| DeepSeek не отвечает | Подождите — он «думает» дольше ChatGPT, это нормально |
