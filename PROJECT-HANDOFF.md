## 1. Что это за проект

**«Мастера Снов: Возрождение»** — возрождение закрытой мобильной онлайн-RPG
«Мастера Снов» (Dreamland Masters, студия Mechanist Games, 2015–2023). Владелец репозитория —
бывший игрок/энтузиаст, исходников оригинала нет. Решено было сделать духовный наследник.

Проект состоит из ДВУХ частей:

| Часть | Где | Статус |
|---|---|---|
| **Веб-демо** (играбельная!) | `prototype/index.html` (полная, ~10.4 МБ) и `prototype/index-lite.html` (вектор, 74 КБ) | ✅ рабочая, активно полируется |
| **Unity-проект** (полная игра под Android/веб) | `unity-project/` | код и контент готовы, сцены не собраны (см. §7) |

Решение владельца: **распространение через свой сайт** (не Google Play), с веб-обвязкой.
Монетизация — отложенная, нативная реклама после стабилизации.

## 2. Ключевые факты и договорённости с владельцем

- Язык общения: **русский**. Термины Unity — английские.
- **Каждое изменение = коммит + пуш + желательно релиз с версией** (тег vX + GitHub Release).
  Владелец явно это потребовал. Ветка: `arena/01a028c2-stunning-octo-pancake` (только она!).
- Веб-демо самодостаточно: весь арт вшит в HTML в base64 (поэтому 10.4 МБ).
- Прогресс игрока — в localStorage (`dm_save_v1`).
- В файле есть **водяной знак сборки** (версия + часы + счётчик кадров) и **кнопка «ОТЧЁТ»**
  (правый верхний угол) — копирует в буфер полную диагностику. Это главный инструмент отладки
  «на расстоянии»: просить владельца жать кнопку и присылать текст.

## 4. Веб-демо: как оно устроено (кратко)

- Один HTML-файл, canvas 1920×1080 (ландшафт), без зависимостей. Код в одном `<script>`.
- «Беговая дорожка»: мир скроллится (camX += 155·dt), герои бегут на месте (homeX),
  враги спавнятся справа (camX+VW+140) и подъезжают ускоренно (+320·dt за экраном).
- Слои параллакса: небо ×0.12 → дальняя полоса ×0.18 → панорама ×0.4 → облака ×0.6 →
  пол ×1.0 → передний план ×1.35. Темы: dream/forest/desert/snow/volcano.
- Персонажи: покадровые позы (idle/walk1-3/atk1-atk2/cast/cast2), кросс-фейд между позами.
- Мета: золото/осколки/уровень отряда (+10%)/призыв Аида (5-й герой) — localStorage.
- Музыка: 3 темы (menu/battle/boss) — процедурный WebAudio-шедулер; SFX позиционные (панорама).
- **Векторный режим**: если через 2.5 с загрузилось <50% картинок → VEC=true, вся графика
  рисуется кодом (горы-синусоиды, плиты, векторные человечки). Лайт-сборка = всегда VEC.
- Версия: `const GAME_VERSION` (подвал меню + водяной знак). Сейчас **v14** / **v14-LITE**.

## 5. Как пересобирать веб-демо

```bash
# после правки index.html или картинок в prototype/art/raw/:
pip install --break-system-packages pillow   # если нет
python3 tools/build_demo_art.py              # вшить арт (хромакей + палитровое сжатие)
python3 tools/build_lite.py                  # пересобрать лайт
```
Правки движка делай прямо в `prototype/index.html` (он же исходник). Арт генерируется
ИИ с фиолетовым #FF00FF фоном → скрипт сам вырезает фон заливкой от краёв.

## 6. Как тестировать (Node-стабы, браузера в песочнице нет)

```bash
# извлечь JS:
python3 -c "import re; open('/tmp/check.js','w').write(re.search(r'<script>([\s\S]*)</script>', open('prototype/index.html').read()).group(1))"
node --check /tmp/check.js                    # синтаксис
```
Стаб-харнессы жили в /tmp и не сохранены — их суть: мокать document/canvas/Image/localStorage,
eval'ить JS, гнать tick(1/60) до battleOver, звать drawMenu/drawBattle. Проверять:
уровни 1–5 = S,W,W,W,W; camX растёт; враг на экране < 3 c; позы героев все 8.
**Полезно оформить их в tools/tests/ при продолжении.**

## 7. Что осталось сделать (приоритеты)

1. ~~ГЛАВНЫЙ БАГ~~ **ИСПРАВЛЕН в v15** (диагноз по «ОТЧЁТУ» владельца):
   `IndexSizeError: ellipse радиус -6` — в JS `(-420*31)%34` даёт отрицательный остаток →
   метки пола давали отрицательный радиус → Chrome бросал исключение КАЖДЫЙ кадр боя →
   отрисовка умирала (статичный полупустой фон, юниты не рисовались; меню работало — там
   координаты положительные). Лечение: (а) Math.abs в формуле меток, (б) глобальная
   обёртка ellipse с |радиусами| и минимумом 0.1 — IndexSizeError невозможен в принципе.
   Тест-доказательство: `tools/tests/chrome_strict_test.js` (эллипс бросает при
   отрицательном радиусе как Chrome; бой с отрисовкой каждого кадра — 0 ошибок).
   **Урок на будущее: Node-стабы обязаны валидировать аргументы как Chrome, иначе
   пропускают такие баги.**
2. Собрать Unity-сцены по `unity-project/README-SETUP.md` (3 сцены, ~3 часа кликов).
3. Миры 2–9 Unity-версии, новые герои до 14+, модели вместо процедурных.
4. Firebase-деплой (`unity-project/docs/FIREBASE-SETUP.md`) → вписать URL в GameConfig.
5. Хостинг демо на сайте владельца (`unity-project/docs/WEB-RELEASE.md`), APK-обвязка.
