# 🔥 NSFW Image Hunter & Downloader для Windows

Мощное и удобное приложение для **поиска, предпросмотра, выбора и пакетного скачивания NSFW изображений и артов** с популярных имиджбордов (Booru) и специализированных API.

---

## ⚡ Быстрый старт (Если на компьютере НЕТ Python)

Вам **не нужно вручную устанавливать Python** или настраивать библиотеки!

1. **[Скачать архив с программой (ZIP)](https://github.com/samagon90/stunning-octo-pancake/raw/arena/01a018e2-stunning-octo-pancake/NSFW_Image_Hunter_Windows_Portable.zip)**.
2. Распакуйте архив в любую удобную папку на компьютере.
3. Запустите файл **`Setup_NSFW_Image_Hunter.bat`** (или `installer.ps1`).

### Что сделает автоматический установщик:
- Сам автоматически загрузит и тихо установит официальный Python для Windows.
- Сам установит все необходимые графические библиотеки.
- Скомпилирует автономный исполняемый файл **`NSFW_Image_Hunter.exe`**.
- Создаст удобный **ярлык на Рабочем столе** («NSFW Image Hunter»).
- Автоматически запустит готовое приложение!

## 🌟 Ключевые возможности

- 🔍 **Многопоточный поиск по популярным источникам:**
  - **Rule34 (xxx)** — крупнейший архив взрослого контента
  - **Gelbooru** — миллионы аниме и NSFW артов
  - **Danbooru** — эталонная каталогизация и детальные теги
  - **Yande.re** & **Konachan** — обои и высококачественные иллюстрации в 4K
  - **Realbooru** — косплей и фотореалистичный контент
  - **Waifu.im** — API нейросетевых и аниме NSFW артов
  - **Safebooru** — безопасные и легкие иллюстрации
  - **Все источники (All Combined)** — одновременный поиск по всем сайтам сразу!

- 🎯 **Удобный выбор изображений:**
  - Чекбоксы на каждой карточке
  - Кнопки **«Выбрать все на странице»**, **«Снять выбор»**, **«Инвертировать»**
  - Умный фильтр **«Только высокое качество (>=1080p)»**
  - Счётчик выбранных файлов

- 🖼️ **Полноэкранный Lightbox-просмотрщик:**
  - Просмотр оригинала в исходном разрешении
  - Полный список тегов (клик по тегу для мгновенного поиска)
  - Информация: ID, автор, разрешение, формат, рейтинг, оценка (Score)
  - Навигация стрелками на клавиатуре (`←` / `→`)
  - Кнопка прямого сохранения отдельного оригинала

- ⚡ **Пакетный загрузчик (Download Manager):**
  - Выбор любой папки для сохранения на диске (кнопка «Обзор...»)
  - Настраиваемый шаблон имени файлов: `{source}_{id}_{tags}`, `{id}`, `{rating}_{id}`
  - Автоматическое создание подпапок по тегу/запросу
  - Защита от повторного скачивания (пропуск дубликатов)
  - Сохранение метаданных и тегов в `.json` файл рядом с картинкой
  - Экспорт выбранных изображений в единый **ZIP-архив** прямо в браузере

- 💡 **Умный поиск:**
  - Автодополнение популярных тегов при вводе
  - Быстрые пресеты (*«Популярное»*, *«Топ рейтинг»*, *«4K Обои»*, *«Бикини»*, *«Lingerie»*, *«Cyberpunk»*)
  - Фильтры по рейтингу: *Только Explicit (NSFW)*, *Questionable (Ecchi)*, *Safe*
  - Фильтры по ориентации: *Горизонтальная (Обои)*, *Вертикальная (Портрет)*, *Квадрат*
  - Фильтры по разрешению: *>= 1080p*, *>= 1440p (2K)*, *>= 2160p (4K)*

## 📁 Файлы в архиве

```
├── Setup_NSFW_Image_Hunter.bat # 🌟 Автоматический установщик "всё включено" (установит всё сам)
├── Start_App_Windows.bat       # Быстрый запуск приложения
├── build_windows_exe.bat       # Ручной запуск сборки EXE
├── build_exe.py                # Скрипт сборки PyInstaller
├── app_gui_qt.py               # Нативное десктопное приложение Windows (PyQt6)
├── app_server.py               # FastAPI бэкенд и локальный веб-сервер
├── app_launcher.py             # Универсальный лаунчер (GUI / Web / Server)
├── requirements.txt            # Список библиотек Python
├── static/                     # Веб-интерфейс
└── core/                       # Модули поиска и загрузки
```
