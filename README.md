# 🔥 NSFW Image Hunter & Downloader для Windows

Мощное и удобное приложение для **поиска, предпросмотра, выбора и пакетного скачивания NSFW изображений и артов** с популярных имиджбордов (Booru) и специализированных API.

Поддерживает работу как в виде **нативного десктопного приложения Windows (PyQt6)**, так и через **интерактивный веб-интерфейс в браузере (FastAPI + Tailwind/JS)**, а также может быть скомпилировано в **автономный `.exe` файл** в 1 клик.

---

## 🌟 Ключевые возможности

- 🔍 **Многопоточный поиск по популярным источникам:**
  - **Rule34 (xxx)** — крупнейший архив взрослого контента
  - **Gelbooru** — миллионы аниме и NSFW артов
  - **Danbooru** — эталонная каталогизация и детальные теги
  - **Yande.re** & **Konachan** — обои и высококачественные иллюстрации в 4K
  - **Realbooru** — косплей и фотореалистичный контент
  - **Waifu.im** — API нейросетевых и аниме NSFW артов
  - **Safebooru** — безопасные и легкие иллюстрации
  - **Все источники (All Combined)** — одновременный поиск по всем сайтам сразу!

- 🎯 **Удобный выбор изображений:**
  - Чекбоксы на каждой карточке
  - Кнопка **«Выбрать все»**, **«Снять выбор»**, **«Инвертировать выбор»**
  - Умный фильтр **«Только высокое качество (>=1080p)»**
  - Счётчик выбранных файлов и общего объёма

- 🖼️ **Полноэкранный Lightbox-просмотрщик:**
  - Просмотр оригинала в исходном разрешении
  - Полный список тегов (клик по тегу для мгновенного поиска)
  - Информация: ID, автор, разрешение, формат, рейтинг, оценка (Score)
  - Навигация стрелками на клавиатуре (`←` / `→`)
  - Кнопка быстрого скачивания отдельного оригинала

- ⚡ **Пакетный загрузчик (Download Manager):**
  - Выбор любой папки для сохранения на диске (диалог выбора папки)
  - Настраиваемый шаблон имени файлов: `{source}_{id}_{tags}`, `{id}`, `{rating}_{id}`
  - Автоматическое создание подпапок по тегу/запросу
  - Защита от повторного скачивания (пропуск дубликатов)
  - Сохранение метаданных и тегов в `.json` файл рядом с картинкой
  - Настраиваемое количество потоков (1–10)
  - Экспорт выбранных изображений в единый **ZIP-архив**

- 💡 **Умный поиск:**
  - Автодополнение популярных тегов (начните вводить `bik...` или `waif...`)
  - Быстрые кликабельные теги в шапке
  - Фильтры по рейтингу: *Только Explicit (NSFW)*, *Questionable (Ecchi)*, *Safe*
  - Фильтры по ориентации: *Горизонтальная (Обои)*, *Вертикальная (Портрет)*, *Квадрат*
  - Фильтры по минимальному разрешению: *>= 1080p*, *>= 1440p (2K)*, *>= 2160p (4K)*

## 🚀 Установка и запуск на Windows

### Вариант 1. Запуск в 1 клик через `run_app.bat` (Самый простой способ)

1. Скачайте репозиторий или клонируйте его:
   ```cmd
   git clone https://github.com/samagon90/stunning-octo-pancake.git
   cd stunning-octo-pancake
   ```
2. Дважды кликните по файлу **`run_app.bat`**.
3. Скрипт сам проверит Python, установит все необходимые зависимости и предложит выбрать режим (Десктопное окно или Веб-интерфейс).

---

### Вариант 2. Запуск Native Desktop GUI (PyQt6)

1. Убедитесь, что у вас установлен **Python 3.10+** (скачать с [python.org](https://www.python.org), обязательно отметьте галочку *"Add Python to PATH"* при установке).
2. Установите зависимости:
   ```cmd
   pip install -r requirements.txt
   ```
3. Запустите десктопное приложение:
   ```cmd
   python app_gui_qt.py
   ```

---

### Вариант 3. Запуск веб-интерфейса в браузере

1. Запустите сервер:
   ```cmd
   python app_launcher.py --mode web
   ```
2. Откройте в любом браузере: **`http://localhost:8000`**

---

### Вариант 4. Сборка самостоятельного `.EXE` файла

Вы можете собрать автономный исполняемый файл `.exe`, который будет запускаться на любом компьютере с Windows даже без установленного Python:

1. Запустите файл **`build_windows_exe.bat`** (или выполните команду `pyinstaller app.spec`).
2. Готовая программа будет создана в папке **`dist/NSFW_Image_Hunter/NSFW_Image_Hunter.exe`**.

## ⚙️ Настройки и шаблоны

В окне настроек (иконка шестеренки или меню настроек) вы можете настроить:
- **Путь сохранения:** например `C:\Users\Username\Downloads\NSFW_Art`
- **Шаблон имени файла:**
  - `{source}_{id}_{tags}.jpg` (например: `rule34_481920_solo_1girl_bikini.jpg`)
  - `{id}.jpg` (только уникальный номер)
  - `{rating}_{id}_{tags}.jpg`
- **Количество потоков:** от 1 до 10 для ускорения загрузки
- **Сортировка:** автоматическое создание подпапок для каждого поискового запроса
- **Метаданные:** сохранение подробных сведений об авторе и тегах в `.json` файл рядом с изображением

## ⌨️ Синтаксис тегов поиска

- `solo 1girl` — поиск артов с одной девушкой
- `highres wallpaper` — высокое разрешение и обои
- `-male -furry` — исключение артов с мужчинами или фурри (знак минус перед тегом)
- `rating:explicit` — только контент 18+
- `score:>100` — только работы с высоким рейтингом
