# Мастера Снов: Возрождение

Возрождение закрытой мобильной онлайн-RPG «Мастера Снов» (Dreamland Masters, 2015).

## 🤝 Новичок здесь? Начни с `PROJECT-HANDOFF.md`
Это полная инструкция: что за проект, где что лежит, как собирать/тестировать и что делать дальше.

- **Unity-версия:** `unity-project/README-SETUP.md`.
